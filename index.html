01 / COMPUTATIONAL SCIENCEPublished · 2025–26

Designing light-driven
hole bifurcation.

How can light drive charge along two different pathways? I develop kinetic models of protein networks that separate oxidizing equivalents into high- and low-energy branches.

Following our ACS Central Science paper, I combined kinetic modeling, XGBoost, SHAP, and Bayesian optimization to map 130,000 candidate energy landscapes and extract design rules for charge separation.

  • Kinetic modeling
  • XGBoost + SHAP
  • Bayesian optimization
  • DFT / MD / QM/MM

02 / SCIENTIFIC AI AGENTSWorking research software

Agentic MEKinetics

An AI assistant with a real physics engine.

I built a master-equation kinetics workbench for charge transport, connecting a Python simulation engine, an interactive dashboard, and a scientific AI assistant.

  • Natural-language model edits pass through scientific validation before simulation.
  • CLI, dashboard, and agent tools share one calculation engine and reproducible result bundles.
  • Grid scans and Bayesian searches explore physical parameter spaces.
Ask→Validate→Simulate
  • Python + TypeScript
  • Sparse numerical solvers
  • Scientific agent tools

A model-edit and simulation workflow has been demonstrated; broader agent evaluation is ongoing.
